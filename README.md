# 公众号视频批量上传助手

Chrome 扩展：在微信公众号后台批量上传视频到素材库，并提供文章排版面板。当前版本 **v0.4.6**，需要 Chrome 116 或更新版本。

## 安装

1. 下载 [v0.4.6 安装包](dist/wechat-video-uploader-v0.4.6.zip)，解压到固定目录。
2. 打开 `chrome://extensions`，开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压后直接包含 `manifest.json` 的文件夹。
4. 登录公众号后台并刷新页面。点击浏览器工具栏的扩展图标可打开视频上传面板；文章排版入口位于页面左下角。

也可以克隆本仓库，直接把仓库根目录作为已解压的扩展加载。使用扩展不需要安装 Node.js 或运行 npm。

更新前保留文章内容，并等待视频任务空闲。替换扩展文件后，在扩展管理页点击「重新加载」，再刷新公众号页面。排版预览和未上传文件保存在当前运行会话中，刷新或重载前请先保留需要的内容。

## 视频上传

从公众号「选择视频 → 素材库」入口或素材库页面打开面板，一次选择多个本地视频。默认后台串行，每次处理一个视频：上传、选择第一张推荐封面并确认、开启原创及确认声明、勾选上传协议、点击「保存」，随后继续下一项。

- 仅保存视频素材，不点击「保存并发表」。
- 可以切换到其他标签页，保持任务页面及浏览器打开。
- 面板标记「已提交」表示已完成保存提交操作，不代表平台转码、审核或原创认定已经通过。
- 重新加载扩展或关闭浏览器后，未完成任务需要重新选择本地文件。
- 使用前请确认所上传内容符合你将勾选的原创声明和服务协议。

后台页面的渲染、风控和上传行为可能变化；遇到问题可使用面板的日志导出功能查看状态。

## 文章排版

1. 从飞书或腾讯文档复制文章，粘贴到「✦ 文章排版」面板。
2. 点击「整理并预览」，检查每段旁边的「正文 / 小标题」识别结果，必要时切换。
3. 在公众号图文编辑页选择「追加到正文末尾」或「替换当前正文」，然后插入。
4. 预览效果后，在公众号中自行保存草稿。扩展不自动保存或发表文章。

排版规则：

- 正文：16px、两端对齐、段后距24px。
- 小标题：20px白字、橙色文字底色、左对齐；底色随文字延伸，可调整颜色，不使用整行色块。
- 去掉汉字与拉丁字母、数字之间的横向空格，保留英文单词、代码和URL内部的空格。
- 保留剪贴板中可用的图片和链接；视频元素或 `[视频]` 占位转换为空行。剪贴板未提供的视频位置无法推断，可以手动补空行。
- 只写正文，不改公众号顶部独立的文章标题或作者栏。

自动插入不兼容时，可点击「复制排版结果」后手动粘贴，或使用「复制并定位正文」再按 `⌘V / Ctrl+V`。原文已在正文中时，请选择替换，避免重复追加。工具支持撤销最近一次插入；如果随后修改了正文，会停止撤销以保护后续编辑。

找不到编辑器时，点击「复制定位信息」。该信息只包含版本、固定路由分类、编辑区和内嵌页面的计数及排除原因，不含文章文字、完整页面URL或登录参数。

## 开发与验证

使用 Node.js 24：

```sh
npm ci
npm test
```

v0.4.6 完整本地回归 **360项通过**，覆盖视频队列、页面适配、排版、插入、定位及诊断。DOM与浏览器接口由本地测试模拟；本地测试不能替代真实公众号页面验收。公众号页面升级可能需要适配。

目录：

- `src/`：扩展脚本。
- `tests/`：本地回归测试及模拟页面。
- `icons/`：扩展图标。
- `dist/`：可直接解压加载的安装包。
- `manifest.json`：Chrome Manifest V3配置。

扩展权限为 `activeTab`、`scripting`、`storage`、`offscreen`；网站访问范围仅限 `https://mp.weixin.qq.com/*`。插件复用用户已登录的公众号页面，不提供账号登录服务。

## v0.4.6 更新

修复旧地址 `media/appmsg_edit` 下新式正文编辑器无法识别的问题。两个已支持的图文入口共用顶层正文识别规则；保留标题作者保护、隐藏节点排除和多候选拒绝。新增识别的通用编辑器走富文本粘贴流程，保留已有排版效果。
